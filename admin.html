Payment settings

Upload the official payment QR to private storage. Do not use a personal or unverified QR.

Participant check-in

Search by registration code, team, email, phone, or participant name. Scan a boarding pass QR to copy its registration code into the search field.

Export live registrations

Downloads an Excel workbook with registration details, short-lived proof links and embedded screenshot thumbnails where supported. Store exports securely and delete them when no longer needed.

Review checklist

1. Open the private proof link. 2. Check UTR, amount, date and payer in the official bank/UPI account. 3. Approve only when the transaction is independently confirmed. 4. Reject with a clear note if it cannot be verified.

Data access

Dashboard access is checked against the authenticated Supabase profile role. Row Level Security remains active on profiles, events and registrations. The service-role key is never shipped to the browser.
